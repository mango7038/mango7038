POSTFLOW STUDIO — ANDROID BUILD (V3)

Ye Android Studio SOURCE PROJECT hai. Is container mein Android SDK nahin hai,
isliye maine nayi APK build/install verify nahi ki hai. Purani 57 KB APK use mat karna.

APK banane ka option 1 (PC):
1. Android Studio install karo.
2. Is folder ko Open Project karo (settings.gradle wala folder).
3. SDK Platform 35 / Build Tools 35 install karo, Gradle sync hone do.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. app/build/outputs/apk/debug/app-debug.apk mobile mein copy/install karo.

Option 2 (GitHub Actions cloud build):
1. ZIP extract karke project ko GitHub repository mein upload karo.
2. Repository > Actions > Build installable Android debug APK > Run workflow.
3. Workflow success hone par PostFlow-Studio-Android-Debug-APK artifact download karo.
4. Artifact ZIP ke andar app-debug.apk rahega; woh mobile mein install karo.

Android test:
